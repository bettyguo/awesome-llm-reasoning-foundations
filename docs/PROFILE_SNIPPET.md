### 📚 Awesome LLM Reasoning Foundations

I maintain [**awesome-llm-reasoning-foundations**](https://github.com/bettyguo/awesome-llm-reasoning-foundations) — a curated, rigorously-verified map of the *theoretical foundations* of LLM reasoning: expressivity, chain-of-thought error bounds, circuit complexity, logical characterizations, learnability of in-context tasks, and knowledge-editing impossibility results.

Distinct from the existing methods-focused reasoning lists. Every entry is web-verified against arXiv / OpenReview / proceedings; weekly CI link-check.

Contributions welcome — PRs need a verification URL.
