# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## In short

- Be respectful of differing viewpoints and experience levels.
- Assume good faith.
- No personal attacks, harassment, or discriminatory language.
- Disagreements over scope, categorization, or technical interpretation are healthy — keep them about the work, not the person.

## Reporting

To report unacceptable behavior, open a private channel with the curator via the GitHub profile contact info, or email the address listed on `@bettyguo`'s GitHub profile. Reports will be handled discreetly.
